# The built-in ASN.1 objects.  The build generates
# include/openssl/obj_mac.h, crypto/objects/obj_dat.h and
# crypto/objects/obj_xref.h from this file; crypto/objects/README.md
# describes the format.
#
# To add an object, append a line at the end of the file,
# with the NID one more than the last one:
#
#   NID:NAME:OID:SN:LN
#
# NID   the object's number, NID_<NAME>.  Part of the API: never
#       changed or reused.
# NAME  the C name: the macros are SN_<NAME>, LN_<NAME>, NID_<NAME>
#       and OBJ_<NAME>.
# OID   dotted decimal.
# SN    the short name.
# LN    the long name, which may contain spaces.
#
# Every line has all five fields.  An empty field means the object has
# none.  Only LN may contain spaces.
#
# A removed object keeps its NID, with "removed" in place of the OID
# and no names:
#
#   NID:NAME:removed::
#
# An alias defines only OBJ_<NAME>, has no NID, and may be anywhere:
#
#   alias:NAME:OID::
