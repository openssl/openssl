# The error reason codes.  The build generates the error headers and
# string tables named in crypto/err/openssl.ec from this file;
# crypto/err/README.md describes the format.
#
# Each line is
#
#   NUMBER:NAME:TEXT
#
# NUMBER  the reason code, unique within its library.  Part of the API:
#         never changed or reused.
# NAME    the reason macro, <LIB>_R_<REASON>, for a library LIB in
#         crypto/err/openssl.ec.
# TEXT    the string ERR_reason_error_string() returns.
#
# To add a reason, add a line at the end of its library's section with
# the NUMBER one more than the last line's.  The TLS alert reasons have
# a section of their own, with the numbers listed in
# crypto/err/openssl.ec.  The SSL section starts with
# SSL_R_INVALID_SESSION_ID, whose number is 999.
