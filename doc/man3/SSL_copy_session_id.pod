=head1 NAME

SSL_copy_session_id - copy the session and configuration of one SSL object to another

=head1 SYNOPSIS

 #include <openssl/ssl.h>

The following function has been deprecated since OpenSSL 4.2, and can be
hidden entirely by defining B<OPENSSL_API_COMPAT> with a suitable version value,
see L<openssl_user_macros(7)>:

 int SSL_copy_session_id(SSL *to, const SSL *from);

=head1 DESCRIPTION

SSL_copy_session_id() sets the session of I<to> to the session of I<from>, as
L<SSL_set_session(3)> would. It also gives I<to> the SSL method, session ID
context and certificate configuration of I<from>. The two objects share the
certificate configuration, so later changes made to it through either object
affect both.

I<to> and I<from> must have been created from the same B<SSL_CTX>, or from
B<SSL_CTX> objects with the same providers loaded. Otherwise
SSL_copy_session_id() may fail.

=head1 RETURN VALUES

SSL_copy_session_id() returns 1 on success and 0 on failure.

=head1 NOTES

This function is deprecated. To resume a session on a new connection, use
L<SSL_set_session(3)>. To create a copy of an SSL object, use L<SSL_dup(3)>.

=head1 SEE ALSO

L<ssl(7)>, L<SSL_set_session(3)>, L<SSL_dup(3)>, L<BIO_f_ssl(3)>

=head1 HISTORY

SSL_copy_session_id() was deprecated in OpenSSL 4.2.
