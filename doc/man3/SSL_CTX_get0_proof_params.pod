=head1 NAME

SSL_CTX_get0_proof_params, SSL_get0_proof_params -
get proof verification parameters

=head1 SYNOPSIS

 #include <openssl/ssl.h>

 OSSL_PROOF_PARAMS *SSL_CTX_get0_proof_params(SSL_CTX *ctx);
 OSSL_PROOF_PARAMS *SSL_get0_proof_params(SSL *ssl);

=head1 DESCRIPTION

SSL_CTX_get0_proof_params() and SSL_get0_proof_params() retrieve an internal
pointer to the proof verification parameters (see L<OSSL_PROOF_verify(3)>) of
I<ctx> or I<ssl> respectively. The returned pointer must not be freed by the
calling application.

When a peer presents a proof, such as a Merkle Tree Certificate, in place of a
certificate chain, it is verified with L<OSSL_PROOF_verify(3)> against the
verification store and the X.509 verification parameters of the connection
(see L<SSL_CTX_get0_param(3)>), with the settings that apply only to proofs
taken from these parameters; for a Merkle Tree Certificate that is the cosigner
quorum set with L<OSSL_PROOF_PARAMS_set_mtc_cosigner_quorum(3)>. The
verification callback is not consulted for a proof.

An B<SSL> takes a copy of the proof-specific settings of its B<SSL_CTX> when it
is created.

=head1 RETURN VALUES

SSL_CTX_get0_proof_params() returns a pointer to an B<OSSL_PROOF_PARAMS>.
SSL_get0_proof_params() returns a pointer to an B<OSSL_PROOF_PARAMS>, or NULL
if I<ssl> is not a TLS connection.

=head1 EXAMPLES

Require a standalone Merkle Tree Certificate the peer presents to be cosigned
by at least one of the trusted cosigners in addition to its CA:

 OSSL_PROOF_PARAMS *params = SSL_CTX_get0_proof_params(ctx);

 if (!OSSL_PROOF_PARAMS_set_mtc_cosigner_quorum(params, 1))
     /* error */
