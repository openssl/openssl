=head1 DESCRIPTION

The parameter name pointers in F<< <openssl/core_names.h> >> provide the same
strings as the corresponding uppercase macros. For example,
B<OSSL_CIPHER_PARAM_padding> points to the string defined by
B<OSSL_CIPHER_PARAM_PADDING>. The namespace remains uppercase, and the
parameter identifier is lowercase.

Use these pointers when constructing L<OSSL_PARAM(3)> arrays at run time to
allow OpenSSL to decode parameter names by pointer comparison. The uppercase
macros remain available and can also be used in static initializers.

The strings use shared private storage. Applications must not change or free
them, or depend on their order or offsets in that storage.

The B<OSSL_CAPABILITY_TLS_GROUP_> and B<OSSL_CAPABILITY_TLS_SIGALG_>
namespaces also have lowercase parameter identifiers.

OSSL_PARAM_is_internal_name() checks whether I<ptr> points into the shared
parameter name storage. It checks the address, not the string contents.
A pointer to a copy of a parameter name is outside that storage.
Pointers within a stored name, including its terminating NUL byte, are inside
the storage.

=head1 RETURN VALUES

Each parameter name pointer refers to a NUL-terminated string.

OSSL_PARAM_is_internal_name() returns 1 if I<ptr> points into the shared
parameter name storage, or 0 otherwise. It returns 0 if I<ptr> is NULL.

=head1 EXAMPLES

Construct a padding parameter with the shared name pointer:

 unsigned int padding = 0;
 OSSL_PARAM params[2];

 params[0] = OSSL_PARAM_construct_uint(OSSL_CIPHER_PARAM_padding, &padding);
 params[1] = OSSL_PARAM_construct_end();
