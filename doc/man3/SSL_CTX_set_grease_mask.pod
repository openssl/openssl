=head1 NAME

SSL_CTX_set_grease_mask, SSL_CTX_get_grease_mask,
SSL_set_grease_mask, SSL_get_grease_mask,
SSL_GREASE_CIPHER_SUITES, SSL_GREASE_SUPPORTED_GROUPS,
SSL_GREASE_KEY_SHARE, SSL_GREASE_SUPPORTED_VERSIONS,
SSL_GREASE_SIGNATURE_ALGORITHMS, SSL_GREASE_EXTENSIONS,
SSL_GREASE_ALL - configure ClientHello GREASE injection points

=head1 SYNOPSIS

 #include <openssl/ssl.h>

 #define SSL_GREASE_CIPHER_SUITES
 #define SSL_GREASE_SUPPORTED_GROUPS
 #define SSL_GREASE_KEY_SHARE
 #define SSL_GREASE_SUPPORTED_VERSIONS
 #define SSL_GREASE_SIGNATURE_ALGORITHMS
 #define SSL_GREASE_EXTENSIONS
 #define SSL_GREASE_ALL

 int SSL_CTX_set_grease_mask(SSL_CTX *ctx, uint32_t mask);
 uint32_t SSL_CTX_get_grease_mask(const SSL_CTX *ctx);
 int SSL_set_grease_mask(SSL *ssl, uint32_t mask);
 uint32_t SSL_get_grease_mask(const SSL *ssl);

=head1 DESCRIPTION

SSL_CTX_set_grease_mask() and SSL_set_grease_mask() select the ClientHello
fields in which a TLS or DTLS client injects GREASE values. The mask only has
an effect when B<SSL_OP_GREASE> is enabled. Setting the mask does not enable
GREASE by itself.

SSL_CTX_set_grease_mask() sets the default mask for B<SSL> objects subsequently
created from B<ctx>. SSL_set_grease_mask() changes the mask for B<ssl> without
changing its parent B<SSL_CTX>. These functions should be called before the
handshake starts.

SSL_CTX_get_grease_mask() and SSL_get_grease_mask() return the configured mask.

The default mask for a new B<SSL_CTX> is B<SSL_GREASE_ALL>, preserving the
behaviour of B<SSL_OP_GREASE> when no mask is configured. A mask of zero is
valid and suppresses every GREASE injection point even if B<SSL_OP_GREASE> is
enabled.

The available mask bits are:

=over 4

=item B<SSL_GREASE_CIPHER_SUITES>

Inject a reserved cipher suite value into ClientHello.cipher_suites.

=item B<SSL_GREASE_SUPPORTED_GROUPS>

Inject a reserved named group into the supported_groups extension.

=item B<SSL_GREASE_KEY_SHARE>

Inject a reserved named group and dummy key exchange value into the key_share
extension. This bit may only be used together with
B<SSL_GREASE_SUPPORTED_GROUPS>, as required by RFC 8701.

A second ClientHello responding to a selected-group HelloRetryRequest omits
the GREASE key share as described for B<SSL_OP_GREASE>.

=item B<SSL_GREASE_SUPPORTED_VERSIONS>

Inject a reserved version into the supported_versions extension.

=item B<SSL_GREASE_SIGNATURE_ALGORITHMS>

Inject a reserved signature scheme into the signature_algorithms extension.

=item B<SSL_GREASE_EXTENSIONS>

Inject both standalone reserved extensions generated by B<SSL_OP_GREASE>.

=item B<SSL_GREASE_ALL>

Enable every injection point listed above.

=back

Setters reject unknown mask bits and reject B<SSL_GREASE_KEY_SHARE> without
B<SSL_GREASE_SUPPORTED_GROUPS>. If a setter fails, the previous mask is
unchanged.

Applications must not retry a failed connection with GREASE disabled. Doing so
would prevent GREASE from detecting and correcting protocol ossification.

=head1 RETURN VALUES

SSL_CTX_set_grease_mask() and SSL_set_grease_mask() return 1 on success and 0
on failure.

SSL_CTX_get_grease_mask() and SSL_get_grease_mask() return the configured mask.
