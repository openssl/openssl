=head1 NAME

SSL_CTX_add1_credential, SSL_CREDENTIAL_up_ref, SSL_CREDENTIAL_free
- manage credentials on an SSL_CTX

=head1 SYNOPSIS

 #include <openssl/ssl.h>

 int SSL_CTX_add1_credential(SSL_CTX *ctx, SSL_CREDENTIAL *cred);

 int SSL_CREDENTIAL_up_ref(SSL_CREDENTIAL *cred);

 void SSL_CREDENTIAL_free(SSL_CREDENTIAL *cred);

=head1 DESCRIPTION

A B<SSL_CREDENTIAL> is a single reference-counted credential an
authenticating party may present in TLS 1.3 or later.  Credentials are
distinct from the default certificate configured with
L<SSL_CTX_use_certificate(3)>.  Functions that create credentials are
documented in their own manual pages, along with the conditions under which
each kind of credential is used.

SSL_CTX_add1_credential() appends I<cred> to I<ctx>'s credentials, taking a
reference to it.  Credentials are used in the order they were added: an
earlier credential is preferred over a later one when more than one is
usable for a connection.  The default certificate, when configured, is used
when no credential is.

SSL_CREDENTIAL_up_ref() takes an additional reference to I<cred>.

SSL_CREDENTIAL_free() releases a reference to I<cred>, freeing it when the
last reference is released.  If I<cred> is NULL nothing is done.

=head1 RETURN VALUES

SSL_CTX_add1_credential() and SSL_CREDENTIAL_up_ref() return 1 on success,
0 on error.

SSL_CREDENTIAL_free() does not return a value.

=head1 SEE ALSO

L<SSL_CTX_use_certificate(3)>

These functions were added in OpenSSL 4.1.
