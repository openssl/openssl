=head1 NAME

X509v3_addr_get_safi - X509 SAFI finder

=head1 SYNOPSIS

 #include <openssl/x509v3.h>

 unsigned int X509v3_addr_get_safi(const IPAddressFamily *f);

=head1 DESCRIPTION

X509v3_addr_get_safi() retrieves the SAFI from the IPAddressFamily data structure.

=head1 RETURN VALUES

X509v3_addr_get_safi() returns the SAFI if it can find it. In the case that
IPAddressFamily does not have it, it returns a value of 0.

=head1 HISTORY

X509v3_addr_get_safi() was added in OpenSSL 4.1.0.
