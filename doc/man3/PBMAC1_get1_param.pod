=head1 NAME

PBMAC1_get1_param - Function to manipulate a PBMAC1
MAC structure

=head1 SYNOPSIS

 #include <openssl/x509.h>

 PBMAC1PARAM *PBMAC1_get1_param(const X509_ALGOR *macalg);

=head1 DESCRIPTION

PBMAC1_get1_param() retrieves a B<PBMAC1PARAM> structure from an
I<X509_ALGOR> structure.

=head1 RETURN VALUES

PBMAC1_get1_param() returns NULL in case when passed incorrect parameters and a pointer to
B<PBMAC1PARAM> structure otherwise.

=head1 CONFORMING TO

IETF RFC 8018 (L<https://tools.ietf.org/html/rfc8018>)

=head1 SEE ALSO

L<openssl-pkcs12(1)>

=head1 HISTORY

The I<PBMAC1_get1_param> function was added in OpenSSL 4.2.0.
